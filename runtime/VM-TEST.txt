Extract the complete package to any local folder; keep bin, plugins, qml and scripts together. No D: drive or SUBST mapping is required. Run deploy-vm.cmd for a manual session. Shell installation remains optional (deploy-vm.cmd install); restore with deploy-vm.cmd restore. Close KDE before moving the directory. After moving an installed copy, run install again from the new location to update registrations; restore before deleting the old location. See docs/FIX24.md. Real VM acceptance is pending.
