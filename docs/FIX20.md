# Fix20：日常程序功能完善

累计包包含 Fix19 及此前全部补丁。重启 VM，覆盖原 CraftRoot 后启动 deploy-vm.cmd。

## 文本编辑器

- Ctrl+F 打开查找栏，F3 / Shift+F3 向后或向前循环查找；失败时保留原光标和选区。
- Ctrl+H 打开替换栏，支持区分大小写、单次替换及全部替换。全部替换合并为一次撤销，替换结果包含原词时不会重复处理插入内容。
- Ctrl+G 跳转指定行；视图菜单提供自动换行和缩放。
- 新增文字随项目语言设置显示中文；保留原有 UTF-8/UTF-16、BOM、换行与原子保存能力。

## 任务管理器

- 暂停自动更新，F5 手动刷新；暂停期间手动刷新不会重新启动计时器。
- 恢复更新后立即刷新，并继续每两秒采样；状态栏明确显示暂停状态。
- 结束进程后的刷新也采用 PID 与创建时间恢复选中项；枚举失败时保留现有列表并显示错误。

## 验证

新增编辑行为测试入口 `plasma-text-editor.exe --editing-self-test`，覆盖循环查找、失败时选区保留、大小写匹配、包含原词的替换及一次撤销。
任务管理器 UI 检查覆盖暂停、手动刷新、恢复；中文编辑器检查验证实际翻译加载。完整检查记录见仓库 manifests/fix20-validation.json。

测试使用隔离的配置和隐藏窗口，没有更改宿主机默认程序、登录注册或安装全局换肤钩子。实际交互仍需虚拟机验收。
