# Fix19：复查与稳定性修复

累计包包含此前所有补丁。重启 VM，覆盖 CraftRoot 后按原入口启动。实际登录与跨进程换肤仍需 VM 验收。

## 本轮修复

- 登录 DLL 部署：先检查目标及祖先路径，再创建目录，拒绝目录联接等重解析点。文件先复制到同目录暂存区，设置权限并验证 SHA-256 后原子发布；校验失败、目标被占用时保留旧文件并清理暂存文件。
- 安装兼容性：统一读取原生 64 位 Program Files，避免 32/64 位 PowerShell 的安装与恢复路径不一致；哈希和 ACL 使用 .NET API，不依赖可能未加载的 Utility/Security 模块。修复 PowerShell 5 将原子替换的空备份参数转换为空字符串的问题。
- 控件撤销：在通知子窗口之前标记恢复状态，防止嵌套窗口消息重复进入清理逻辑。回调持有状态引用，窗口在绘制期间重入销毁时延迟释放，并立即停止后续绘制；隐藏窗口回归测试验证引用存活及最终释放。
- 后台服务命令：严格解析完整参数，拒绝拼写错误或混用参数；停止服务不再要求先加载绘制 DLL，恢复入口在 DLL 缺失时仍可工作。
- 会话退出：当前用户配置了原生 KDE 会话宿主、Plasma 正常退出且没有系统 Shell 时，也回退 Explorer；已有桌面时避免多开资源管理器窗口。

## 验证

新增实际文件系统测试覆盖原子替换、错误哈希、锁定目标、暂存清理和创建目录前的联接拒绝。跨位 PowerShell 的只读计划验证使用同一受保护目录。其余测试复查控件绘制与撤销、严格参数解析、会话回退决策以及此前的 UI/终端/归档/关联功能。

测试没有注册登录提供程序、安装全局钩子或验证真实账户密码。登录模块仍为实验性本地账户提供程序，使用说明见 [LOCAL_LOGON.md](LOCAL_LOGON.md)。
