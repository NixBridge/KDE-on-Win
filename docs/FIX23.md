# Fix23：桌面工具轻量修复

本轮仅检查 Fix22 桌面工具，保留 Fix1–Fix22 累计功能；不修改登录组件、Shell 核心或引入依赖。

## 修复与改进

- 修复配置保存曾失败、随后成功时仍显示旧错误的问题，恢复当前快捷键状态提示。
- 设置入口现在将键盘焦点放到快捷键配置；历史入口仍聚焦列表。
- 工具隐藏时不再随复制反复重建历史列表；重新显示（含非 IPC 打开路径）时同步刷新，历史采集策略不变。
- 空历史显示中文/英文提示，区分暂无记录与记录已关闭；无历史时禁用清空按钮，无选中项时保持复制按钮禁用。

## 验证

- 实际编译 x64 `plasma-desktop-tools` 与项目翻译资源，只部署这两个输出；未重编无关组件。
- 5 项相关检查通过：模型自测、英文 UI、中文 UI、翻译目录检查、累计部署入口检查。
- UI 回归覆盖空/非空/禁用状态、隐藏后更新及直接重新显示、两个入口的逻辑焦点目标、配置失败后成功恢复；保留已有 IPC、最小化恢复和清理断言。
- Qt offscreen 使用合成 MIME 和私有配置/IPC，不读取宿主剪贴板、不注册真实快捷键；焦点断言验证窗口的逻辑目标，不代表实际桌面激活已验收。
- 342 条中文翻译已完成，格式占位符检查通过。本轮没有重跑全量回归或进行真实 VM 验收。
- 累计 ZIP 需通过 CRC、清单源文件逐字节检查，并保留 Fix22 全部条目。

## 使用与 VM 待验收

退出 VM 内 KDE 后，将 `plasma-windows-20261110-fix23.zip` 覆盖原 CraftRoot，运行 `deploy-vm.cmd`，不必逐个安装旧补丁。

VM 检查：从历史/设置入口打开并按 Tab；清空和禁用历史；隐藏后连续复制再打开；验证真实焦点、深浅色和高 DPI 显示；配置不可写后恢复可写并重新保存，确认旧错误消失。

Fix22 已记录的限制继续存在，包括未实现的应用会话恢复及需 VM 验证的全屏、多屏、真实剪贴板/快捷键和 Shell 恢复。
