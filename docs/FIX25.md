# Fix25：原生集成、恢复安全与桌面工具

基线：Fix24 `644ac9d`。保留 Fix1–Fix24，沿用任意本地目录运行能力。需求正文仍写 Fix24，但该版本已交付，因此本轮使用 Fix25，不覆盖旧文档。没有增加登录提供程序、默认切换 Shell 或引入第三方依赖。

## 确认的问题

| 程度 | 实际问题 | 修复 |
| --- | --- | --- |
| 高 | 交互式 Shell 管理器和旧低级脚本在重复安装时覆盖原始备份；多个入口各自实现写入和恢复 | 两个脚本 UI 和通用切换脚本复用同一事务，独占锁、首次创建备份、严格 UTF-8 / 空备份校验，写入失败回滚；不再用 New-Item -Force 重建已有键，保留同键其他值 / 子键；不会把缺失备份时的当前 KDE Shell 再备份成“原始 Shell” |
| 高 | 托盘切入 Plasma 时，仅凭进程存在就结束原有 Explorer，关闭用户已有的资源管理器窗口 | 保留 Explorer；停止函数禁止终止 Explorer；切回时使用系统绝对路径并等待桌面出现，超时保留 Plasma，命令行失败返回非零；托盘修改 Shell 前要求已有可读、非空 UTF-8 恢复备份，否则提示先使用明确的安装入口 |
| 高 | 延迟安装 Qt 标题栏时修改窗口 flags，会隐藏可见的模态框并提前结束 exec | 可见对话框直接调整原生框架，不重建 / 隐藏 Qt 窗口；保留隐藏对话框原有样式测试，并增加模态存活测试 |
| 高 | IPC 调度模态运行框期间，超时可先删除 socket，回调返回后再访问已失效对象 | 弹窗调度前完成连接清理；私有 IPC 回归等待超过原超时时间并验证先断开、后关闭运行框 |
| 中 | WindowList 不保存 WinEvent Hook，析构不解除；实际后端也没有对象所有者 | 保存并解除全部 Hook；实际后端归 QApplication 管理，QPointer 防悬空，禁止无应用 / 非 GUI 线程初始化，退出后不重建 |
| 中 | 标题、状态、几何主要依赖两秒轮询；句柄复用可能残留旧 PID 条目 | 合并 50 ms 内的名字、状态、位置、最小化和 cloak 事件；按行刷新；纯几何事件不重新提取图标；移除失效身份，复用 HWND 时重建记录；前台为无独立任务项的模态框时，沿有限 owner 链映射到所属任务 |
| 中 | 无激活的临时顶层窗口仍被当作普通任务 | 按 WS_EX_NOACTIVATE / WS_EX_APPWINDOW 的组合排除不应出现的窗口，保留明确要求任务栏入口的窗口（包括具有隐藏 owner 的安装器窗口） |
| 中 | 原生会话宿主可重复启动多个等待进程 | 使用会话内单实例对象，重复调用退出；后台 spawn 模式保持独立 |
| 低 | 快捷键或 IPC 可在运行框的嵌套事件循环中再次打开运行框 | 复用当前输入框，取消后解除引用 |
| 低 | 从历史复制旧文本后，最近使用顺序没有更新 | 显式提升现有条目一次，继续忽略内部剪贴板标记，避免重复记录和监听循环 |
| 中 | 旧切换脚本的延迟展开破坏 ! 路径，额外参数被静默忽略 | 禁用延迟展开，Shell 路径作为独立参数传给 PowerShell，严格检查多余参数，干跑不写备份 |
| 低 | 系统设置“打开日志”实际打开配置目录 | 统一到会话宿主使用的 logs 子目录，目录缺失时创建并检查失败 |

注册表安全依据：[New-Item 的 Registry Force 语义](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/new-item)。

窗口事件 API 依据：[SetWinEventHook](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwineventhook)、[扩展窗口样式](https://learn.microsoft.com/en-us/windows/win32/winmsg/extended-window-styles)。保留原有保守分组、全屏面板策略和原生 Alt+Tab，没有通过持续激活或新增置顶循环处理问题。图标单独变化仍有缓存 / 慢速刷新回退，不声称所有应用图标即时更新。

## 常用位置与快速操作

开始菜单打开 **“快速操作与常用位置”**；或运行 `plasma-desktop-tools.exe --actions` / `plasma-kde-launcher.exe quick-actions`。这是既有桌面工具的新入口，不是独立控制中心。

窗口顶部“常用位置”提供主目录、下载、文档、图片、桌面（Known Folder API 解析，交给 Dolphin），以及此电脑和回收站。后两者保留 Windows 虚拟 Shell 页；当前运行时没有 KIO trash 模块，不伪装成 Dolphin 已完整支持回收站。

“快速操作”提供 Windows 设置、项目显示设置、项目任务管理器、Dolphin、Konsole、Windows 系统信息、会话日志。缺少已知组件时禁用对应菜单；实际创建 / 启动失败有提示。菜单项中文本地化。测试只检查计划和界面，不在宿主打开这些系统操作。

## 主题与快捷键

系统设置 → 外观 → **跟随 Windows 深浅色模式（仅 Breeze）**，默认关闭。手动选择 Breeze 深浅色会关闭自动跟随；检测到自定义 KDE 配色或 Plasma 主题时不覆盖，高对比度模式下跳过跟随。保留自定义强调色和字体。

现有桌面工具接收 Windows 设置广播，并监听配置文件；150 ms 合并变化后复用个性化助手。已是目标颜色时不写配置、不重复启动，支持现有 QWidget / Plasma / Kirigami 同步链路。助手启动失败保留待应用状态并反馈；不是任意 WinUI、自绘界面或全部第三方主题的统一换肤。

快捷键仍使用原来的两组修饰键，默认 Ctrl+Alt+Shift+E/R/D/V。基础重复检查、注册失败的完整组合 / Windows 错误原因已接入现有状态提示；不会强占 Meta+E/R/D，不增加低级键盘 Hook。应用内部快捷键、AltGr 与不同键盘布局的所有冲突无法由 RegisterHotKey 检出，仍需实际验证。

## 诊断导出

系统设置 → 关于与诊断 → **预览并导出诊断信息**。先展示完整 JSON，再由用户选择保存，不自动上传。

内容：打包版本 / Git 提交与 dirty 标志、Windows / Qt / 已知 KDE 文件版本、少量组件存在和本导出器已加载状态、当前会话且位于本运行目录的受管理进程数量、白名单配置开关及整数。缺少元数据时不伪造 Commit。打包脚本在提交后生成 build-info.json。

默认不输出完整环境、用户名、个人路径、命令行、剪贴板、密码或凭据。只汇总固定名称日志的大小和最近最多 64 KiB 的错误标记数，**不导出原始日志文本**，避免依赖不可靠的密码正则清洗。组件存在检查不是完整依赖诊断；发布时另外执行 PE 导入检查。仍应在分享前检查报告。

## 编译与回归

- 实际编译 x64 KWindowSystem 核心 / Windows 插件、taskmanager、受影响的原生应用 / 启动器 / 开始菜单插件 / 会话宿主 / shellswitch、回归探针及中文翻译。x86 与登录代码未改、未重编；运行既有 x86 与合成登录测试。
- 完整主回归 64 项；新增 Known Folder 操作计划、主题 opt-in / 自定义保护 / 幂等、快捷键失败说明、诊断敏感字段排除、进程内 HWND 事件与重复清理、真实后端生命周期、合成注册表 Shell 事务。运行记录为 work/fix25-test-results.json。构建新增事件探针需传 `-DWINDOWS_EVENT_SOURCE=<已应用本轮补丁的 KWindowSystem 源目录>`，或在干净配置前设置 `KDE_KWINDOWSYSTEM_SOURCE`；未构建探针时不能把相关回归记为通过。
- Windows 事件探针既检查实际后端所有权 / 线程限制 / 应用退出后的失效，也使用仅监听本进程的 Hook 检查自己的可视区域外窗口；不操作用户窗口。现有窗口 / 多屏几何检查仍保留。
- Qt 界面使用 offscreen、私有配置和合成 MIME；未注册真实桌面工具热键、读取宿主剪贴板或安装控制换肤 Hook。Shell 失败注入使用模拟注册表命令，另在 HKCU 项目专用随机 GUID 测试键验证真实 provider 保留其他值与子键并清理该叶键；不触碰真实 Winlogon。文件都在私有临时目录。
- 379 条中文翻译、格式占位符检查；源归档固定哈希，KWindowSystem 3 个和 workspace 22 个补丁严格重放，与 7 个实际编译源码 / 头文件逐字节一致。见 manifests/fix25-source-verification.json。
- 本轮没有真实 VM 交互验收，也没有在宿主安装登录组件或修改默认 Shell / 文件关联。保留上游 Qt 弃用 API 警告，没有把编译成功称为零警告。

## 已知限制及审查范围

复查了 Fix20–Fix23 的自有应用、剪贴板、通知、窗口后端、托盘与启动入口；Fix24 路径回归保留。没有逐行审计全部 Qt/KDE 上游实现。原生通知权限和应用点击激活、网络共享超时、双向拖放、回收站失败、设备热插拔、睡眠恢复、所有第三方自绘窗口 / 高对比度显示仍需 VM。未确认的问题不做推测性修改。

实验性登录只检查既有代码、部署 / 恢复入口并运行合成测试，不改提供程序、不注册新 DLL、不修改受保护文件。应用会话恢复仍未实现。持续运行的第三方服务输出可能继续增长；导出只限量读取，不声称已对所有日志实现实时轮转。

原生会话宿主的自动回退仍依赖退出码、当前 Shell 配置和原生桌面存在状态；对于正常退出同时 Explorer 消失、但注册值已不指向本宿主的交错情况，不保证自动拉起 Explorer。保留托盘切回和任务管理器运行 explorer.exe 的恢复途径；未在缺少真实注销状态证据时盲目增加重启，仍需 VM 故障注入。

恢复备份沿用历史文本格式，保存 Shell 值；不是任意第三方 Shell 注册表类型 / 缺失状态的完整快照。历史上已经覆盖或丢失的原始备份无法自动重建；先恢复 Explorer 或人工检查，拒绝猜测。托盘第一次修改 Shell 前必须先由 `deploy-vm.cmd install` 创建备份。安装、卸载及真实登录仍需 VM 验收。

## 累计补丁与 VM 验收

关闭 VM 中 KDE 的全部组件，把 Fix25 全量累计 ZIP 覆盖原完整运行目录，运行 deploy-vm.cmd。包含 Fix1–Fix24，不逐包安装，不要在 DLL 使用中覆盖。搬家和关联重新注册规则继续见 FIX24.md。

1. 无 D 盘、中文 / 空格路径普通启动、重复启动、缺 DLL / 缺会话脚本、总线超时；确认 Explorer 仍可用，服务不无限重启。
2. 默认 Shell 重复安装 / 恢复、已有自定义 Shell / 损坏备份 / 缺失原始备份、权限失败；先保留快照。托盘首次无备份应拒绝，切入 Plasma 不结束原 Explorer 窗口。
3. 多窗口、标题和图标更新、最小化 / 最大化 / 恢复 / 关闭、隐藏 / uncloaking、无激活工具窗口；确认无残留任务项或误关闭。
4. 全屏游戏、无边框 / 普通最大化、Alt+Tab、任务栏点击、置顶应用；确认不把桌面壁纸提升到普通应用前面。
5. 100/125/150/200% 单 / 双屏、负坐标、主屏切换、插拔 / 分辨率变化；检查面板、菜单、工作区和窗口可见性。
6. Known Folder 重定向、下载 / 文档 / 图片 / 桌面、本地盘 / UNC、中文快捷方式；文件复制 / 移动 / 删除 / 占用 / 拖放仍由 Dolphin 执行并检查其真实反馈。
7. Windows 深浅色广播、自定义 KDE 主题、高对比度、关闭跟随、手动主题优先；检查各支持界面同步，助手缺失时提示和重试。
8. 热键占用、两组修饰键、AltGr / 中文输入 / 多布局；Meta+E/R/D、Alt+Tab、Ctrl+C/V 保留原生行为。
9. 反复打开运行框、取消 / 回车、历史选择 / 清空 / 禁用、明确敏感标记和剪贴板占用；不应叠框、重复记录或重启后保留历史。
10. 托盘图标反复创建 / 销毁、Explorer 重启、菜单位置 / 关闭、通知超时 / 点击 / 源应用退出，以及休眠 / 唤醒。
11. 诊断预览 / 取消 / 保存 / 不可写目标，手动检查 JSON 不含个人路径、秘密、完整环境或原始日志；缺组件应反映为缺失，而不是验收通过。
