# Fix24：运行目录可迁移

完整包可解压到任意本地普通目录，文件夹不必叫 CraftRoot，不要求 D 盘，不再建立 SUBST。保留 bin、plugins、qml 和根目录脚本的相对结构。

- 移除 deploy-vm / session-shell 的固定构建目录检查及磁盘映射。
- 包内启动器以自身目录为准，覆盖继承环境中失效的 CRAFT_ROOT；Qt 使用已有的相对 qt.conf。
- D-Bus 服务、Plasma / NightTime / KRunner 的入口元数据使用 PATH 中的程序名；启动环境优先当前包的 bin。D-Bus 根配置明确指定包内相对服务目录。
- 菜单用 UTF-8 XMLWriter 写入，正确转义中文、空格和 & 等路径；开始菜单缓存重建不再回退到开发者的目录。
- 安装和关联仍使用当前目录的绝对路径注册，不默认启用 Shell 或登录替换，不修改受保护文件。

## 使用

新用户：解压完整便携包，运行根目录 deploy-vm.cmd。旧用户：关闭 KDE，把 Fix24 全量累计补丁覆盖现有完整包，也可以把整个运行目录移到其他盘再启动。

需要默认 Shell 时仍可主动执行 deploy-vm.cmd install；恢复用 deploy-vm.cmd restore。已安装副本搬家前应先恢复，搬家后从新目录重新安装，文件关联也从新目录重新注册；Windows 注册的路径不会自动随文件夹移动。通知开发包需要从新位置重新注册。实验性登录组件保持独立安装到受保护位置，不从任意用户目录直接注册 DLL。

“任意目录”指具有正常读取/执行权限的本地路径，包含空格、中文及常见符号；不会绕过 ACL、安全策略或系统路径长度限制。UNC / 网络共享上的 Shell 启动、超长路径及包含 CMD 百分号变量表达式的路径尚未验收，不保证支持；可先复制到本地运行。

## 验证与 VM 待测

运行目录回归使用私有临时目录和配置，验证普通及中文/空格/&/括号/!路径、继承旧 CRAFT_ROOT 和 delayed expansion 的场景；验证菜单 XML 路径与累计入口。没有在宿主注册关联、切换 Shell 或启动真实桌面。实际编译组件无改动，本轮无需重编。

仍需 VM 验收：无 D 盘的其他路径首次启动、D 盘已被其他用途占用、从新目录安装/退出/恢复 Explorer、搬家后重新注册、真实 Dolphin/通知及多屏桌面交互。自动化和依赖加载结果不能替代这些交互验收。
