# Fix15：标题按钮对比度

相对于原始 VM 包的累计覆盖包，包含此前所有补丁。重启虚拟机，覆盖 CraftRoot，再运行 `deploy-vm.cmd`。

标准窗口装饰和项目自有窗口的最小化、最大化/还原、关闭按钮，现在使用 Breeze 图标的透明度形状，并按各自标题栏的实际背景重新着色，避免全局图标缓存中的白色覆盖浅色标题栏。前景色与背景的对比度不足 4.5:1 时回退为黑色或白色。显式提供普通、悬停、禁用、选中图标，避免 Qt 再生成低对比度版本。

主题、窗口局部调色板、激活状态和最大化状态变化会更新按钮。图标按配色和状态缓存，未变化时不重复生成。自绘标题栏程序仍保持原有行为。

回归测试覆盖故意错误的白色全局图标配色、浅色/暗色/灰色背景、激活与未激活组、四种按钮图形和四种图标模式，以及真实 QWidget 标题栏的局部配色变化。VM 中仍需使用 Notepad3 等截图中的程序验证实际显示与主题切换。
