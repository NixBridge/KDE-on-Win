# Fix13: 标题栏、中文设置和个性化同步

这是覆盖**原始虚拟机运行包**的累计补丁，包含此前所有修复。
重启虚拟机，将补丁覆盖解压到原 CraftRoot，再运行 `deploy-vm.cmd`。

## 标题栏

覆盖区域现在包含左侧原生图标。原生窗口坐标、DWM 可见边框与覆盖层定位统一使用
物理坐标，支持不同 DPI 感知模式的窗口。拖动消息会转换到目标窗口的坐标空间。
覆盖层保留上边缘和角落的缩放操作，不会盖住应用菜单与客户区。

最大化还原按钮同时检查 Qt 与 Win32 窗口状态。全局覆盖层的还原动作直接调用
Windows 还原接口，避免因为系统菜单的暂时状态而无法还原。
自绘标题栏、高完整性级别或其他用户的窗口仍按原有范围跳过。

## 设置与中文

自有应用新增 289 条简体中文翻译，并加载 Qt 标准对话框的中文翻译。
默认跟随 Windows 界面语言；可在“关于与诊断”中选择中文或 English，重新打开设置后生效。
其他已经运行的自有工具重开后使用所选语言。Konsole、Dolphin 等上游应用保留各自的语言机制。
中文界面默认使用 Windows 提供的 Microsoft YaHei UI；没有复制或分发 Windows 字体。

* 显示：分辨率、刷新率、方向，测试模式并在 15 秒未确认时恢复。
* 声音：枚举播放设备，分别调整音量与静音。选择要调整的设备不会更改默认输出。
* 网络：DNS、自动 IPv4 DHCP、管理员启动入口。
* 蓝牙：无线设备设置，后台搜索经典蓝牙设备，配对和移除配对。
* 语言与输入：已安装的输入布局、已安装的 Windows 显示语言，下次登录生效。
* 通知：免打扰时长、弹窗位置和时长、通知声音、任务按钮角标，以及通知转发授权。
* 账户：当前本地账户显示名称和密码。修改操作只对与当前登录令牌 SID 匹配的本地账户启用。
* 电源：真实电源计划，接通电源和使用电池时的屏幕／睡眠超时；失败时恢复旧值。
* 更新：主动检查、勾选更新、查看和接受许可、下载与安装、结果及重启需求。
  安装前会复验更新 ID、修订号和许可内容；本应用不会主动重启。
  安装期间正常关闭设置会被阻止，完成后可手动选择重启。

显示缩放、新显示语言包安装、BLE 配对、默认音频输出切换、静态 IP／Wi-Fi 管理、
Microsoft 或域账户的云端资料管理尚未提供。没有用跳转到 Windows 设置的按钮代替这些功能。
蓝牙配对使用系统配对对话框。系统配置和更新可能需要管理员权限，在“关于与诊断”中有入口。
这些系统修改必须由用户在虚拟机中操作，自动检查不会在宿主机上执行。

## 个性化同步

深浅色、强调色、字体和字号会写入 KDE 全局配置及项目颜色方案，通知已运行的组件更新。
Plasma Shell 也加载此项目的 Breeze 样式；面板、菜单、通知和自有窗口可使用同一套颜色。
强调色包含选中、焦点、悬停和链接颜色。标题栏按钮图标也随深浅色刷新，避免暗底黑图标。默认 Breeze 桌面主题跟随颜色方案。
Kirigami 的 Windows 字体变更监听已修复，无需重开菜单才更新字体。

面板的大小、方向、隐藏方式、透明度和浮动配置，桌面壁纸，以及开始菜单列数、图标大小和
侧栏项目沿用实际 Plasma／菜单配置通道。成功的请求会清除待应用标记，不会每次登录覆盖
之后手动修改的配置。只改颜色或字体不会重设面板布局或壁纸。
配置失败会显示状态；等待 Plasma 启动的请求会保留并重试。

配置与日志位于 `%LOCALAPPDATA%\plasma-win-session`：
`appearance.ini`、`current.colors`、`personalization.log`。
Windows 上通用 KDE 配置目录通常是 `%LOCALAPPDATA%`，包含 `kdeglobals` 和 `plasmarc`。

自有应用的关于／项目入口指向 https://github.com/NixBridge/KDE-on-Win 。
上游应用保留上游关于信息和版权。

## 验证范围

自动检查覆盖真实的 QWidget、Plasma 主题与 Kirigami 颜色／字体往返切换，中文窗口和字形、
翻译完整性、隐藏窗口标题区域及还原按钮、菜单与 QML 模块、终端会话、压缩包和运行库依赖。
新版 Plasma Shell 与 Kirigami 均由固定官方源码重编译；规范补丁在核对 SHA-256 的干净源码上复验。

仍需虚拟机验收多屏混合 DPI 下的拖动／缩放、真实桌面的层级及各系统设置的实际应用。
Windows 更新安装失败会显示系统结果代码，不会据此宣称所有更新已成功。
