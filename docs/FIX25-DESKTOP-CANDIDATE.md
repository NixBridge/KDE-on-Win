# Fix25 Hotfix6 桌面候选包

- 全量覆盖包显式携带 Qt 和 KDE QML 模块、原生小部件、桌面及面板资源。发布前检查 PE 导入依赖；Qt、KDE 或输入法插件漏出清单都会触发检查失败。
- 临时会话启动时，桌面资源同步失败会写入诊断日志，包含出错目录和启动阶段。
- 默认布局遇到任务管理器创建失败时继续加载其余组件，并记录出错原因。已保存的布局仍由 Plasma 使用。
- 桌面、编辑层、面板、文件夹视图、启动菜单及图像壁纸的 QML 编译由回归套件检查。Windows 菜单模型另测实际创建和搜索；双击运行、桌面层级和原生小部件初始化仍需在实际会话验证。

完整桌面的验收条件包括壁纸和桌面图标正常、面板与原生任务项可交互、系统托盘与时钟可用、启动菜单可以打开应用，以及退出后 Explorer 可正常使用。目前只有自动化与打包验证，候选包尚未取得 Windows 11 VM 交互验收。
