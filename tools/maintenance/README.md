# Historical maintenance helpers

These scripts supported bootstrap downloads and regeneration of the original malformed patch sets. They are kept for provenance and targeted repair work, not used by the normal build/package path. Release builds use tools/configure-port.py and the verified canonical patches under upstream/plasma-windows/patches.

Download manifests and experiment output belong in work/ and are not committed. Run maintenance scripts from the repository root unless their command-line options say otherwise.
